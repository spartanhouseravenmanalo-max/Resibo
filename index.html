Resibo

Receipt encoder for BIR VAT and income tax returns
Open this in Chrome or Safari. You seem to be inside another app, such as Messenger. Google sign-in and the camera may not work here. Tap the menu (three dots) and choose Open in browser or Open in Chrome, or copy the link and paste it into Chrome or Safari.

Add receipts

Take a photo, or upload receipt images or PDF files. The page reads the text on your device, fills in the TIN, invoice number, date and VAT, then you check each one before exporting. One receipt per photo, flat, in good light.

        Set up sync
        
    
        
      
        One-time setup, about 10 minutes and free. Your receipts are stored in your own Firebase project under your Google account. Only you can read them.
        
      
          
        
        1. Go to console.firebase.google.com and click Add project. Name it resibo. You can turn Google Analytics off.
          2. 
        
        2. Open Build, then Authentication, click Get started, choose Google, switch it Enable, pick your email as the support email and Save.
          3. 
        
        3. In Authentication, then Settings, then Authorized domains, click Add domain and enter 
          4. 
        
        4. Open Build, then Firestore Database, click Create database, choose a nearby location (Singapore is closest) and Production mode. Then open the Rules tab, replace everything with the rules below, and click Publish.
          
          rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /{path=**}/receipts/{id} {
      allow read, write: if request.auth != null
        && request.auth.token.email_verified == true
        && request.auth.token.email == 'MASTER-EMAIL@gmail.com';
    }
  }
}
          
          
          Replace MASTER-EMAIL@gmail.com with the Gmail address of your master account, in lowercase. Only that account can see and edit everyone's receipts. Other accounts only see and change their own.
          5. 
        
        5. Click the gear icon, then Project settings. Under Your apps click the web icon </>, name it resibo, and register it. Copy the firebaseConfig block it shows.
          6. 
        
        6. Phone sign-in fix. In Firebase open Authentication, Sign-in method, Google and copy the Web client ID (under Web SDK configuration). Then open console.cloud.google.com, choose the same project, go to APIs & Services, then Credentials, click Web client (auto created by Google Service), and under Authorized JavaScript origins click Add URI and enter  then Save. It can take a few minutes to apply.
